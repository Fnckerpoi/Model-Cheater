## 这是什么

**码的挂B** 是一个开源系列的**总入口**，不是一个单点工具。

它承载一整套体系：把记忆、知识、经验、流程从人脑里搬进可复利、可验证、可迁移的外部系统，让一个人的成长曲线从线性累积变成 **RSI（Recursive Self-Improvement，递归自我改进）**：每一轮做事都让下一轮更快，而不是重新来过。

名字是个玩笑——给「码」这件事装个**外挂**（Model-Cheater）。外挂不是作弊，是把重复劳动交给机器，把认知和判断留给自己。

## 核心理念

| 原则 | 含义 |
| --- | --- |
| **记忆外包，认知和判断不外包** | 记住什么交给系统，怎么理解、做什么决定留给自己。机器负责不忘，人负责想深。 |
| **复利而非积累** | 一条经验沉淀一次，处处复用（Memory / Skill / Preset / 工具），而不是每个项目从零学起。 |
| **带宽还给认知** | 记忆外包省下的精力，不是用来多做事，而是投进理解、建模与复盘——认知随轮次增长，而不是原地空转。 |
| **结论有界，证据分层** | 区分「已验证 / 已失败 / 未验证」。前一关通过不算后一关通过，叙事不能替代证据。 |
| **开源整套体系** | 不是零散脚本合集，而是可以拼起来跑通的方法论 + 实现。 |

### 为什么是 RSI

人类做不到 RSI，不是因为不会改进，而是因为**改进的载体太贵**：经验写在脑里会遗忘，写在文档里会过时，教会别人要重复一遍。

当记忆、知识与流程可以被外部承载、被检索、被复用、被自动执行时，改进的回路才闭合：

```
   ① 做事    Agent 执行，人只做判断和积累认知
        │
   ② 沉淀    记忆 / 知识 / 规则 / 流程落盘
        │
   ③ 复用    Skill · Preset · 工具链，一次沉淀处处生效
        │
   ④ 改进    流程与判断标准升级，认知增长
        │
        └───────► 回到 ①：回路闭合，下一轮更快
```

这条回路上，每样东西都有明确的去处：

| 去处 | 内容 | 原因 |
| --- | --- | --- |
| 交给硅基 | 记忆、知识、流程——存起来就能用的 | 硅基存得准、找得快、执行稳；脑子不该当硬盘用 |
| 留给自己 | 认知与判断——理解为什么、决定做什么 | 内化无法代劳；判断交出去，回路就没有主人 |

所以记忆外包省下的不只是时间，更是**认知带宽**：原本用来记住琐事的那部分精力被释放出来，投进理解、建模与判断——这才是真正让人变强的部分。机器的复利在仓库里，人的复利在脑子里，两个回路互相喂。

人从**执行者**变成**回路的设计者**。这是本系列所有项目共享的同一个目标。

### 如何新增一行

1. 「维护方」写明**本人 / 他人 / fork 自谁**——自己的项目和在用的他人项目都要标清楚，不冒认来源。
2. 「角色」按实际状态选择：**自研**（本系列产出）、**fork / 在研**（在他人基础上改造）、**在用**（直接使用，注明上游）、**参考**（仅收录，尚未确认使用或接入）。
3. 把仓库按 **入口 → 编排 → 记忆 → 执行** 归到某一层，写进「方向」列。
4. 一句话说明写**它解决什么问题**，不写技术栈清单。
5. 提交 PR，或在 Issue 里给一行表格内容。

### 如何新增一行

1. 写清**接触时点**（什么阶段遇到它）和**它改变了什么**——改变要具体到思维方式，而不是「很有启发」。
2. 推荐理由必须是你自己的经历，不是转述他人的评价。
